# Md Biplob Hosen — Personal Website

Source for my personal academic website, published with GitHub Pages at
**[hosenmb.github.io](https://hosenmb.github.io/)**.

I'm a PhD student in Information Systems at the University of Maryland,
Baltimore County (UMBC), working on machine learning, responsible AI,
fairness, and AI in education.

## Built with

Plain HTML, CSS, and vanilla JavaScript — no build step. A single shared
stylesheet (`styles.css`) and a small progressive-enhancement script
(`script.js`) power a responsive, mobile-friendly layout with automatic
light/dark theming.

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | Home — bio and news/updates |
| `research.html` | Publications |
| `professional.html` | Teaching experience and student supervision |
| `education.html` | Education |
| `achievements.html` | Awards and achievements |
| `misc.html` | Miscellaneous |
| `onePage.html` | Standalone single-page version |
| `styles.css` | Shared styles (light + dark, responsive) |
| `script.js` | Mobile navigation menu |
| `favicon.svg` | Site icon |
